Connection and security tips

Enter an executable or a full HTTPS URL (localhost HTTP is allowed). Each local argument goes on its own line, never through a shell. Use ${workspaceFolder} in a command, argument, or environment value to refer to the selected working folder. Local servers run from that folder.
